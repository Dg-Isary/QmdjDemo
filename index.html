▶ 👀 30 秒入门：这张盘是什么？我该看哪里？ （点击展开 · 纯讲解，不会改变任何排盘结果）
① 一张盘 = 一个舞台 + 三组演员
  • 🏛️ 地盘：九宫格 + 九个天干。永远不动，是整张盘的地基。
  • ☁️ 天盘：九星 + 天盘天干。随时干转，代表"天时/大环境"。
  • 🚪 人盘：八门。随时支转，代表"人的行动方式"。
  • ✨ 神盘：八神。跟着值符转，代表"现场氛围/隐性助力"。

比喻：地盘是舞台，天盘是天气，人盘是演员的动作，神盘是全场的气氛。四层叠在同一格里，才产生吉凶。

② 一个格子里有六样东西（记住读的顺序）
神 八神（如 值符/白虎）
隐 暗干 · 空空亡 · 马驿马
星 九星（如 天蓬/天心）
天 天盘天干（浮在上面）
门 八门（如 休门/开门）
地 地盘天干（压在下面）

读格口诀：先看门和星定事，再看天地两干论生克，最后看神来定氛围。底部还写着宫名、方位、五行与四害标签（击刑/入墓/门迫）。

③ 三步上手（建议按顺序学）
  1. 在上方选一个案例（或自己改四柱），页面自动出盘。
  2. 点「下一步」：右侧会逐步告诉你"这一步在算什么、为什么这么算、盘上该看哪里"，每一步都有大白话 + 常见误区。
  3. 点任意宫格看深度剖析；学完去「通关题库」自测，答错会直接给你对应步骤的复习入口。

小技巧：带虚线下划线的词都可以悬停看解释；键盘 ← → 可翻步；🎬 动画 开关可关闭飞行特效，旁边可调速。

奇门遁甲（时家转盘）九步排盘法 · 硬核全流程精讲

古人云：“学会奇门遁，来人不用问。”奇门遁甲排盘看似繁复，实则是由严密的数学天文周期（洛书九宫、六十甲子、二十四节气）层层咬合而成的四层转盘模型（地盘、天盘、人盘、神盘）。以下为您逐一拆解全部九个步骤的底层逻辑、口诀与边界处理规则：

① 先看精讲

本页每步都有「口诀 + 一句话理解 + 常见误区」，先建立整体印象。

② 再动手推

口诀：冬至惊蛰一七四，小寒二八五同推，大寒春分三九六，立春八五二相随，雨水九六三无失，清明立夏四一七，谷雨小满五二八，芒种六三九是真；夏至白露九三六，小暑八二五重逢，大暑秋分七一四，立秋二五八流通，处暑一四七相应，霜降小雪五八二，寒露立冬六九三，大雪四七一宫同。

四、奇门四害（六仪击刑、奇仪入墓、门迫、马星）铁律速查

1. 六仪击刑（能量损耗最烈、拧巴难受）

天盘六仪落入与其所遁旬首地支相刑之宫：

  • • 戊（甲子戊）落 震三宫(卯)：子卯相刑
  • • 己（甲戌己）落 坤二宫(未)：戌未相刑
  • • 庚（甲申庚）落 艮八宫(寅)：寅申相刑
  • • 辛（甲午辛）落 离九宫(午)：午午自刑
  • • 壬（甲辰壬）落 巽四宫(辰)：辰辰自刑
  • • 癸（甲寅癸）落 巽四宫(巳)：寅巳相刑
2. 十干入墓（能量被囚困，有力使不出）
  • • 甲/癸（木/水）墓在 坤二宫(未)
  • • 乙/丙/戊（木/火/土）墓在 乾六宫(戌)
  • • 丁/己/庚（火/土/金）墓在 艮八宫(丑)
  • • 辛/壬（金/水）墓在 巽四宫(辰)
3. 八门门迫（门克宫为门迫，事倍功半）

口诀：“吉门被迫吉不就，凶门被迫祸重重”。即八门五行克制所落宫位五行：

• 伤/杜(木)落坤二、艮八(土) | 景门(火)落乾六、兑七(金) | 生/死(土)落坎一(水) | 开/惊(金)落震三、巽四(木) | 休门(水)落离九(火)。

4. 驿马星（主变动、出行、提速、冲空冲墓）

依时支三合局头冲位定马星（永远在四维角宫）：
• 申子辰时 → 马在寅（艮八宫） | • 寅午戌时 → 马在申（坤二宫）
• 巳酉丑时 → 马在亥（乾六宫） | • 亥卯未时 → 马在巳（巽四宫）
