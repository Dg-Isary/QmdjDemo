## 项目简介

奇门遁甲的排盘规则环环相扣：定局、排地盘、寻旬首、转天盘、转人盘、转神盘、排暗干、标四害，任何一步算错，整张盘就全错。但传统教材往往只给结论、不给过程，初学者很难建立"为什么这么排"的直觉。

本项目把这些步骤做成一个**可交互的教学演示**：

- 每一步都告诉你**在算什么、为什么这么算、盘面上该看哪里**；
- 每一步都有**飞星 / 飞门 / 飞神的动态过程**，能直观看到"星从老家宫飞到了新宫"；
- 学完能立刻在**同一页面**用题库自测，答错直接跳回对应步骤复习。

全部代码在一个 `index.html` 里，不需要 Node、不需要构建、不需要后端，丢到 GitHub Pages 就能用。

## 功能特性

### 1. 分步排盘演练器

- **九步推演**：`1 排四柱 → 2 定阴阳局 → 3 排地盘 → 4 寻旬首符使 → 5 转天盘 → 6 转人盘 → 7 转神盘 → 8 排暗干长生 → 9 标四害成盘`
- **全动态演示**（可按步骤播放，也可整段自动播放）：
  - 九星从各自本宫**飞入**新宫，天盘干紧随落下
  - 八门按"值使随时支"的落点飞入
  - 八神从值符宫起，按阳顺阴逆依次飞出
  - 值使步进用**光点逐宫跳动**，每落一宫弹出「数至:丙寅」气泡
  - 目标宫位脉冲光环、四害标签逐个弹出
- **动画开关 + 速度调节**（慢速 / 标准 / 快速），自动播放节奏自动跟随动画时长
- **右侧同步讲解**：每一步固定给出四块内容
  - 🗣️ 这一步在干什么（大白话）
  - 🎯 打个比方
  - 🔍 此刻请看盘面（配合高亮，告诉你眼睛该放哪）
  - ⚠️ 最容易错的地方
- **盘面位置标注**：每格内标出 `神 / 星 / 门 / 天 / 地`，新手也能分清四层（可一键关闭）
- **术语悬停词典**：值符、值使、旬首、空亡、驿马、击刑、入墓、门迫、伏吟、反吟、符头、暗干、克应、寄宫等 26 条，鼠标停留即出白话解释
- **宫位深度剖析**：点击任意宫格，查看四盘要素、十干克应、门迫/击刑/入墓/空亡/马星、天地盘十二长生
- **全局格局识别**：九星伏吟、八门伏吟、九星反吟、八门反吟、五不遇时、六甲旬首时，以及全盘十干克应扫描
- **键盘操作**：`←` `→` 翻步

### 2. 九步全流程精讲

每步包含「口诀 + 底层逻辑 + 一句话理解 + 常见误区」，并可从卡片直接跳到演练器对应步骤演示。

### 3. 速查表与底层字典

- 二十四节气三元七十二局完整对照表（阳遁 / 阴遁）
- 六十甲子六甲旬首、六仪遁干、符头三元、旬空速查表
- 洛书九宫 · 原始九星 · 原始八门属性表
- 奇门四害（六仪击刑 / 十干入墓 / 八门门迫 / 驿马星）铁律速查

### 4. 通关题库

8 道实战推算题，覆盖拆补定元、旬首推算、地盘排布、中五寄宫、值使步进、八神方向、击刑与门迫。每题可展开「💡 提示」看解题思路，答完后可一键跳回对应步骤复习。

### 5. 内置 7 个经典教学案例

| 案例 | 局式 | 演示重点 |
| --- | --- | --- |
| 案例一 | 阳遁八局 · 丙戌日 辛卯时 | 标准阳遁顺排全流程 |
| 案例二 | 阴遁七局 · 壬辰日 丙午时 | 阴遁逆布九宫与八神逆转 |
| 案例三 | 阳遁五局 · 丁巳日 甲辰时 | 六甲旬首时 → 星门全伏吟 |
| 案例四 | 阳遁一局 · 己卯日 甲子时 | 伏吟对照（与局数无关） |
| 案例五 | 阳遁一局 · 戊申日 戊午时 | 四组十干克应同盘（青龙返首等） |
| 案例六 | 阳遁一局 · 丁巳日 甲辰时 | 旬首落中五宫 → 天禽值符寄坤二、死门为值使 |
| 案例七 | 阳遁一局 · 戊辰日 辛酉时 | 九星八门全反吟（对冲） |

## 快速开始

### 方式一：直接打开

双击 `index.html` 即可（需要联网加载 Tailwind CDN 与 Google Fonts）。

### 方式二：本地静态服务（推荐）

```bash
# Python 3
python -m http.server 8080

# 或 Node
npx serve .
```

浏览器打开 <http://localhost:8080>。

### 方式三：部署到 GitHub Pages

1. 把仓库推到 GitHub；
2. **Settings → Pages → Source: Deploy from a branch**，选择 `main` 分支、`/ (root)` 目录；
3. 等待片刻，访问 `https://<你的用户名>.github.io/<仓库名>/`。

> 入口文件名必须为 `index.html`，本仓库已按此命名。

## 使用指南

1. **选局**：顶部点一个教学案例，或自己修改四柱干支 / 节气 / 局数（局数可选手动指定阳遁阴遁 1~9 局）。
2. **逐步推演**：点「下一步」，观察盘面元素飞入 + 右侧讲解；也可以点「自动演示」连续播放，或「⚡ 一步成盘」直接出完整盘。
3. **看细节**：点任意宫格，右侧出现该宫的深度剖析；鼠标悬停带虚线的术语可看解释。
4. **自测**：切到「通关题库」，答错会给出对应步骤的复习入口。

排盘规则设置（定局法则 / 中五宫寄宫 / 暗干排法）在顶部下拉框中，切换后会立即重算。

## 排盘规则与算法说明

> 计算逻辑集中在 `calculateQimenChart()` 一个纯函数中，输出一个 `chart` 对象；所有渲染函数只读取该对象，不参与计算。

| 步骤 | 规则 |
| --- | --- |
| **定局** | 由节气定阴阳遁；由日柱往前（过去方向）找最近的「甲 / 己」日为符头；符头地支 **子午卯酉→上元、寅申巳亥→中元、辰戌丑未→下元**；查该节气三元表得局数（拆补法） |
| **地盘** | 固定队列 `戊 己 庚 辛 壬 癸 丁 丙 乙`；几局则「戊」落几宫，阳遁顺飞九宫、阴遁逆飞九宫 |
| **旬首** | 旬首地支 =（时支序号 − 时干序号 + 12）mod 12；六甲分别遁于 `戊己庚辛壬癸` |
| **值符 / 值使** | 旬首遁干在地盘的落宫，其**本位九星为值符**、**本位八门为值使**；若落中五宫，则天禽为值符，值使借寄宫（坤二死门 / 艮八生门）之门 |
| **天盘** | 「值符随时干」：时干（为甲时取旬首六仪）地盘落宫即值符新宫；其余八星按外圈顺时针序列 `蓬→任→冲→辅→英→芮(禽)→柱→心` 依次排布，每颗星带走本宫地盘干作为天盘干 |
| **人盘** | 「值使随时支」：从旬首宫起，按**九宫数字**阳顺阴逆逐宫步进，数到时支落点即值使门位置，其余七门按 `休→生→伤→杜→景→死→惊→开` 顺时针排满外圈 |
| **神盘** | 「小值符随大值符」：八神之首起于天盘值符落宫，按 `值符→腾蛇→太阴→六合→白虎→玄武→九地→九天` **阳遁顺时针、阴遁逆时针**排布 |
| **暗干** | 时干加于值使门落宫后按阳顺阴逆飞布九宫；若该宫地盘干与时干相同则先入中五宫起飞 |
| **四害** | 六仪击刑（戊3/己2/庚8/辛9/壬4/癸4）、十干入墓（甲癸→坤2、乙丙戊→乾6、丁己庚→艮8、辛壬→巽4）、门迫（门克宫）、驿马（申子辰马在寅、寅午戌马在申、巳酉丑马在亥、亥卯未马在巳） |
| **格局** | 伏吟 / 反吟（按九星、八门整体是否居本宫或对冲宫判定）、五不遇时（时干同性克日干）、六甲旬首时，以及十干克应扫描 |

口诀与规则依据传统通行说法整理，用于教学演示。

## 技术实现

- **单文件**：结构、样式、排盘引擎、交互全部在 `index.html`，无打包、无依赖安装。
- **样式**：Tailwind CSS（Play CDN）+ 少量自定义 CSS（五行配色、金边质感、动画关键帧）。
- **字体**：Noto Serif SC（盘面 / 标题）+ Inter（正文）。
- **渲染**：原生 JS + 模板字符串，按 `currentStep` 控制四层信息的显示层级。
- **动画**：CSS `@keyframes` + 元素级 CSS 变量（`--fx-dx` / `--fx-dy`）实现"从 A 宫飞到 B 宫"的位移；独立的 `#qimen-fx` 图层承载光点、气泡与脉冲光环。
- **状态**：`currentChart`（排盘结果）+ `currentStep` / `selectedPalace`（视图状态）三个变量驱动全部视图。

## 浏览器兼容

支持 Chrome / Edge / Firefox / Safari 的近期版本（需支持 CSS 自定义属性、`aspect-ratio`、`matchMedia`）。

已做响应式适配，手机端可用；盘面在窄屏下会取消强制正方形，避免大字号撑破格子。

系统若开启「减少动态效果」（`prefers-reduced-motion: reduce`），动画会自动降级为静态显示。

## 已知限制

- **置闰法为预留选项**：下拉框可切换，但当前版本定局仍统一按拆补法推算（置闰的超神/接气/置闰逻辑尚未接入）。
- **节气按"日"粒度**：未内置精确交节时刻表，跨节当天的边界情况可能与专业软件存在差异。
- **十干克应词典为精选子集**（约 22 组常用组合），并非全部 100 组。
- **需要联网**：Tailwind CDN 与 Google Fonts 为外部资源；如需完全离线，可改用 Tailwind 构建版并把字体本地化。
- 排盘结果为教学演示用途，未做多流派（如飞盘奇门、刻家奇门）适配。
